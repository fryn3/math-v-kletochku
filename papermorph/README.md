# Уроки у доски: рабочие файлы

Второй вариант уроков «Математики в клеточку» в стиле [Papermorph](https://github.com/DozenTwelve/Papermorph): каждая тема — анимированный урок с озвучкой, проверками прямо в кадре и практикой. Готовая книга лежит в [`uroki/`](../uroki/) и открывается по адресу `/uroki/` рядом со справочником. Справочник ведёт к урокам: пункт меню «Уроки у доски», строка на главной и кнопка «Урок у доски» на странице каждой темы (`js/app.js`, по списку `uroki/course.js`).

Книга собрана целиком: 40 тем в 9 главах, как в справочнике (папки `ch01`–`ch40`), около пяти часов уроков. Глава 3 «Обыкновенные дроби» — пилот, его автор одобрил; остальные темы сделаны по его образцу и ждут просмотра автором. Статус каждой темы — в `books/uroki/chapters.md`.

Эта папка — исходники, из которых книга собирается скиллом Papermorph. Сайту она не нужна.

| Путь | Что в нём |

## Как устроена книга

- Раздел книги — глава справочника, глава книги (папка `uroki/chNN`) — тема справочника. `NN` — сквозной номер темы в курсе: тема 3.1 — 13-я по счёту, поэтому `ch13`. На экране показывается номер темы (`CHAPTER.label`).
- Список курса — `uroki/course.js` (`window.UROKI_COURSE`): глава, её цвет, первая папка и темы с минутами. По нему строится оглавление `uroki/index.html` (глава появляется, когда у всех её тем стоят минуты), справочник ставит ссылку с темы на урок (если на её месте в курсе готовый урок с тем же названием), страница озвучки берёт названия тем.
- `uroki/lib/engine.*`, `math.js`, `contents.*`, `units.*`, `volume.*` — копия движка Papermorph (engine-v2.12). Руками не правится, обновляется скриптом `engine.py`.
- `uroki/lib/book.css` — оформление книги: зелёная доска движка в бледную клетку.
- `uroki/lib/kletka.js` — общие элементы уроков: полоски, круги-«пиццы», числовой луч, дроби с цветными числителем и знаменателем, титульная карточка, итоги. Свои элементы урок держит у себя под префиксом `cNN` (`c34Plane`); те, что пригодятся другим урокам, перечислены в `chapters.md`.
- Финальная реплика каждой темы начинается одинаково: «Отлично! Тема «…» пройдена…» и называет следующую тему.

## Команды

Скилл: `~/.claude/skills/papermorph` (дальше `SKILL`). Нужны `uv`, `ffmpeg`, сеть при первом запуске озвучки (модели Silero и Vosk, раздел «Голос и ударение») и браузеры Playwright (`uv run --with playwright playwright install chromium firefox`).

Предпросмотр (из корня репозитория; без кэша браузера):

```bash
python3 ~/.claude/skills/papermorph/scripts/serve.py 8766 .
```

Книга: http://localhost:8766/uroki/, справочник: http://localhost:8766/.

Озвучить урок после правки текста или ударений (меняются только изменённые шаги; перенос метки не требует новой записи):

```bash
uv run --python 3.11 --with torch --with vosk --with numpy --index https://download.pytorch.org/whl/cpu --index-strategy unsafe-best-match python papermorph/tools/uroki/silero_tts.py papermorph/content/uroki/ch13/narration.ru.json uroki/ch13/audio/ru
```

Режим проверки озвучки — страница «Озвучка уроков» (http://localhost:8767/, раздел «Страница озвучки (режим проверки)»); команда запускает её и открывает в браузере, а если она уже работает — просто открывает (`papermorph/golos ch41` — сразу тема ch41):

```bash
papermorph/golos
```

Весь текст озвучки с ударениями, как их ставит Silero (для проверки; та же команда `uv run`, другой скрипт):

```bash
uv run --python 3.11 --with torch --with vosk --with numpy --index https://download.pytorch.org/whl/cpu --index-strategy unsafe-best-match python papermorph/tools/uroki/silero_stress_text.py papermorph/content/uroki/ch*/narration.ru.json > /tmp/udareniya.md
```

Проверки всей книги (для одной темы — её папка вместо списка):

```bash
python3 ~/.claude/skills/papermorph/scripts/lint.py uroki --content papermorph/content/uroki --brief papermorph/books/uroki
```

```bash
uv run --with playwright python ~/.claude/skills/papermorph/scripts/check.py $(cd uroki && ls -d ch[0-9]*) --url http://localhost:8766/uroki/ --browsers chromium,firefox
```

В Chromium `check.py` может вывести одно предупреждение «Did not find element … rel=expect href="#bar"»: оно из заголовка движка, а не из уроков.

Тесты уроков в Chromium и в Firefox (каждый печатает «… passed»; если Chromium из Playwright не запускается, укажите установленный браузер в `CHROME`):

```bash
for f in papermorph/tools/uroki/e2e_ch*.py; do uv run -q --with playwright python "$f" || echo "FAILED $f"; done
```

```bash
for f in papermorph/tools/uroki/e2e_ch*.py; do BROWSER=firefox uv run -q --with playwright python "$f" || echo "FAILED $f"; done
```

Кадры урока одним листом (раскадровка):

```bash
uv run --with playwright --with pillow --with numpy python ~/.claude/skills/papermorph/scripts/strip.py ch13 /tmp/ch13 whole:end divide:end --sheet storyboard --url http://localhost:8766/uroki/
```

Видео урока (MP4 с субтитрами, вопросы пропускаются):

```bash
uv run --with playwright --with numpy python ~/.claude/skills/papermorph/scripts/export.py ch13 --url http://localhost:8766/uroki/ --out /tmp/video
```

## Голос и ударение

Голос книги — Silero TTS, локально и бесплатно: модель `v5_6_ru`, голос xenia, темп 78 % от собственного темпа Silero (при нём книга идёт так же долго, как шла голосом Edge). Так записано в начале каждого `narration.ru.json`: `"engine": "silero"`, `"voice": "xenia"`, `"rate": "78%"`; `tts.py` такой файл не озвучивает, поэтому голос Edge не перепишет книгу по ошибке. Silero выбрал автор на слух из пяти проб (Azure с исправленным IPA, Google Chirp 3 HD, Silero, Piper, Vosk; сравнение и цифры — `books/uroki/review/udareniya/varianty.md`, вне git). До 2026-11-15 голосом книги был Edge ru-RU-SvetlanaNeural: он сам выбирал ударение в омографах, ошибался и разметки не принимал, а та же Светлана через Azure с IPA искажала гласные.

`silero_tts.py` пишет то же, что писал `tts.py`: mp3 каждого шага (24 кГц, с паузой 0,2 с до голоса и 0,9 с после и громкостью −21 LUFS, как у Edge), время слов в кэш `narration.ru.timings.json` и `timings.js`. Шаг озвучивается заново, когда меняется его текст, куски ударений, голос или темп; перенос метки `[[…]]` только пересчитывает время. Модели скачиваются при первом запуске в `~/.cache/papermorph/` (Silero — 141 МБ, Vosk — 45 МБ).

- **Ударение.** Silero ставит ударения сам, в том числе в омографах, и в части слов ошибается («коробку́», «три ра́вно восьми»). Ударение задаётся куском в `content/uroki/chNN/narration.ru.stress.json`: `{"шаг": ["кусок текста", …]}`. Кусок — часть произносимого текста шага (без меток `[[…]]`) со знаком U+0301 после ударной гласной каждого слова, которое нужно задать: `"Сравни чи́сла."`, `"два числа́?"`. Без знаков кусок должен встречаться в шаге ровно один раз (е и ё не различаются); если нет — добавьте соседнее слово. Silero получает «+» перед этой гласной; «ё», написанная в куске, читается как «ё». Текст урока и субтитры остаются без знаков. После правки — `silero_tts.py` для этой темы.
- **Проверка ударений глазами.** `silero_stress_text.py` печатает весь текст озвучки с ударениями так, как их ставит сам Silero (его собственный расстановщик, тот же, что внутри голоса): у каждого слова из двух и больше слогов — знак ударения; **жирным** — где Silero выбирал между двумя ударениями или между «е» и «ё» сам, _курсивом_ — ударения из кусков. В начале — список слов, где он выбирал сам, по частоте. Расстановщик берётся через `silero_tts.accentor()`: модель Silero хранит решатель омографов сжатым и восстанавливает его веса только при первой озвучке, а без этого он читает омографы иначе, чем голос. До 2026-11-15 текст печатался без восстановления и в 42 словах книги расходился с записями: голос говорит «ра́вно» (18 мест), «соро́к», «у́же», «пято́й», «вы́читают», «стрелки́», «пары́», «коробку́» и др., а текст показывал верное ударение. Страница озвучки показывает то, что говорит голос.
- **Время слов.** Silero его не даёт: каждый клип распознаёт Vosk (`vosk-model-small-ru-0.22`) только по словам этого шага, и услышанные слова сопоставляются с текстом по порядку (незнакомое Vosk слово он слышит как похожее на том же месте, и время остаётся верным). Vosk слышит слово на 0,07 с позже, чем его ставят Edge и Azure, — столько и вычитается; слово, которое не нашлось, ставится посередине между соседями. Проверено на 16 шагах, озвученных Azure (его время слов — точное): после поправки у половины слов ошибка до 0,014 с, у 99 % — до 0,11 с.
- **Лицензия.** Модели Silero — CC BY-NC-SA 4.0: только некоммерческое использование и с указанием Silero; указание стоит на обложке книги (`uroki/index.html`). Книгу с таким голосом нельзя продавать.

Пробная фраза с временем слов:

```bash
uv run --python 3.11 --with torch --with vosk --with numpy --index https://download.pytorch.org/whl/cpu --index-strategy unsafe-best-match python papermorph/tools/uroki/silero_tts.py --say "Сравни чи́сла." /tmp/proba.mp3
```

Ударения кусками заданы во всех 221 месте с омографами из прежней проверки (числа, часа, стороны, места, цены, длины, кружки, воды, руки, шкалы, голоса, слова, острова, поезда, реки, ребра, трубы, сорока, ряда, шага, шара), с поправками автора: «уравнение в два ша́га», «три красных ша́ра». Ещё 115 кусков исправляют явные ошибки самого Silero, найденные по его тексту с ударениями: «равно́» (он говорил «ра́вно»), «дро́би», «все» (он говорил «всё множители»), «зна́ком», «величи́ны», «стои́т», «раздели́», «пото́м» и другие. Решения Silero в омографах зависят от соседних слов, поэтому после новых кусков текст с ударениями стоит собрать заново. Счётная форма после «два, три, четыре» — «два часа́», «три шага́», «две стороны́»; после дроби и слов «часть», «половина» — «ча́са».

## Страница озвучки (режим проверки)

Режим проверки озвучки — локальная страница «Озвучка уроков» на http://localhost:8767/. Запуск из корня репозитория — `papermorph/golos` (`papermorph/golos ch41` — сразу тема ch41; другой порт — числом, `--no-open` — не открывать браузер). Команда сама поднимает `tools/uroki/voice_review.py` через `uv` с torch, vosk и numpy; если страница уже работает, она только открывает её. В приложении Claude — конфигурация `golos` в `.claude/launch.json`. Silero грузится секунд пять, ещё с полминуты страница считает по всей книге, где голос выбирал ударение сам. Сайту и опубликованной книге страница не нужна и ничего в них не добавляет.

- Слева — главы и темы: прослушано шагов из скольких, жёлтое число — слова, где Silero выбирал ударение сам, «●» — несохранённые правки и предложения, «!» — запись не совпадает с текстом или кусок ударения не находится в тексте.
- Текст шага — так, как его скажет голос: ударная гласная красным; жёлтым — омографы (Silero сам выбирал ударение или «е/ё»), их стоит проверить на слух; подчёркнуто зелёным — ударение задано куском. Во время воспроизведения подсвечено звучащее слово.
- Клик по слову — варианты ударения (клавиши 1–9). «Авто» убирает заданное ударение, «▶ Отсюда» играет с этого слова, «Найти в книге» показывает все шаги с этим словом. Галочка «так же везде в этом списке» ставит выбранное ударение этому слову во всех шагах списка, где голос говорит его иначе (с поиском «равно» — по всей книге).
- «Озвучивать сразу» (вверху): после выбора шаг озвучивается в черновик и играет с этого места; «▶ Было» и «▶ Стало» — сравнить. Черновики — в `books/uroki/review/golos/` (вне git); повторная та же правка готова сразу.
- «Сохранить» (клавиша S) пишет в книгу то, что слышно в черновике, как это сделал бы `silero_tts.py`: куски в `narration.ru.stress.json` (прежние куски остаются как были; новое ударение — кратчайший кусок вокруг слова, который встречается в шаге один раз), mp3 в `uroki/chNN/audio/ru/`, время слов в `narration.ru.timings.json` и `timings.js`. Ключ записи тот же, что у `silero_tts.py`, поэтому сохранённое он потом не переозвучивает. «Сохранить все N» — все изменённые шаги списка. Сохранённое видно в `git diff`, коммит — как обычно; после сохранения — `check.py` для темы (анимация шага не должна стать длиннее озвучки).
- **«К проверке»** — очередь: всё, что изменено и не сохранено, сервер хранит в `books/uroki/review/golos/pending.json`, так что правки переживают перезагрузку и закрытие страницы. Туда же можно поставить предложение со своим пояснением: `POST /api/draft` с `{"ch", "beat", "text", "forms", "note"}` (например, когда Claude хочет, чтобы автор послушал спорное место). Каждое — послушать «▶ Стало» и сохранить или отменить.
- «✎ текст» — правка текста шага (Ctrl+Enter — применить). Метки `[[…]]` должны остаться те же и в том же порядке, иначе текст не принимается. Текст пишется в `narration.ru.json`.
- «▶ Подряд» играет шаги один за другим и дальше следующую тему; дослушанный до конца шаг отмечается «прослушан» (`books/uroki/review/golos/heard.json`). Пробел — пауза, ↑/↓ — шаг, ←/→ — 3 секунды, R — сначала. Фильтры: омографы, заданные, не прослушанные, изменённые.
- «урок ↗» открывает урок на этом шаге, «Книга ↗» — всю книгу; этот сервер раздаёт её без кэша, и в уроке, открытом отсюда, вверху справа есть кнопка «🎙 Озвучка»: шаг, который сейчас на экране, открывается на странице озвучки (урок встаёт на паузу). Сервер помечает свои ответы заголовком `Server-Timing: golos`, по нему кнопку показывает `uroki/lib/kletka.js`; на сайте и на других серверах её нет.

## Новая тема или переделка

1. Дикторский текст в `content/uroki/chNN/narration.ru.json` (в начале — `"engine": "silero"`, `"voice": "xenia"`, `"rate": "78%"`; числа словами, метка `[[имя]]` перед словом, на котором что-то происходит), озвучка `silero_tts.py`; ударения проверить на слух на странице озвучки (там же исправить и сохранить) или глазами `silero_stress_text.py`, неверные — куски в `narration.ru.stress.json` и снова `silero_tts.py`.
2. Страница `uroki/chNN/index.html` по образцу `ch13`: шаги `[id, заголовок, (m, D) => { … }, { ask }?]`, время действий — `m('метка')`.
3. Минуты в `uroki/course.js`, `CHAPTER.next` у предыдущей темы, строка в `chapters.md`. Название темы в `course.js` — как в справочнике: по нему справочник ставит ссылку на урок.
4. `lint.py`, `check.py`, раскадровка `strip.py`, тест `e2e`.
5. Ударения в новой теме Claude расставляет сам (так решил автор 2026-11-15, проверив на слух все 26 исправлений): читает текст, как его скажет голос (`silero_stress_text.py` или страница озвучки), каждый омограф и каждое слово, названное помощником в отчёте, сверяет со смыслом фразы, ставит куски в `narration.ru.stress.json` и переозвучивает тему, затем `check.py`. Автор, когда хочет, слушает тему в режиме проверки: `papermorph/golos chNN`, «▶ Подряд».

Темы делались так: по одному помощнику на тему по заданию `books/uroki/worker-brief.md`; координатор смотрел лист кадров каждой темы, возвращал на доработку то, что читалось неверно, и регистрировал главу целиком.
