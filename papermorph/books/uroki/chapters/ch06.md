## Решения

- Цвета: буквы (коробочки для чисел) — KL.DEN, подставленные числа — KL.NUM, клетки площади — KL.TWO, правило и спрятанный знак «·» — KL.RULE.
- Порядок следствий справочника изменён: сначала подстановка вместе со «знак умножения можно не писать» (это же нужно для ловушки), потом прямоугольник, потом формула пути и обратные формулы; общее правило «если a · b = c, то a = c : b» — после пути, как обобщение.
- Добавлено: шаг «буква — коробочка» (одна запись a + 3 для трёх чисел) и вывод площади по рядам клеток, периметра — обходом сторон.
- Задачи справочника: 7x − 3 при x = 6 → q1, поезд 240 км за 4 ч → q3, велосипедист → final3. Ответы проверены.
- В справочнике ошибок не найдено.
- Свои помощники (c06): `c06Fly` (строка, часть токенов которой слетается с уже стоящих на доске), `c06Grid` (прямоугольник клеток одним путём), `c06Car`, `c06Train`, `c06Road`. `c06Grid` и `c06Fly` могут пригодиться другим урокам.
- still.py: в `wrap` паузы между пунктами `klWrap` (как во всех уроках); в `letter` пауза 24–29 с убрана метками `val`, `name`.
