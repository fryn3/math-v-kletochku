# Математика в клеточку

Справочник по математике 5–6 класса. В каждой теме дано общее правило, из него выведены частные правила с примерами. Дальше идут частая ошибка и задачи с проверкой ответа.

**Сайт:** https://fryn3.github.io/math-v-kletochku/

## Что внутри

40 тем в 9 главах: числа и действия, делимость, обыкновенные дроби, десятичные дроби и проценты, отношения и пропорции, отрицательные числа, геометрия, текстовые задачи, диаграммы с перебором вариантов и вероятностью. В каждой теме есть ссылки на правила, на которые она опирается, и на темы, где она используется дальше. Шпаргалка собирает все правила на одной странице.

После каждой главы есть экзамен из 8 задач в трёх вариантах:

- **варианты 1 и 2** — на сайте (`#ekzamen-3-1`, `#ekzamen-3-2`). Ребёнок решает их сам, программа ставит оценку и называет темы, которые стоит повторить;
- **вариант 3** — только на странице для родителей: https://fryn3.github.io/math-v-kletochku/roditelyam.html. Ссылки на неё с сайта нет, поисковикам она закрыта. Родитель отмечает главы и печатает листы с заданиями (одна работа на лист) и ключ ответов с короткими решениями. Если открыть страницу в браузере ребёнка, рядом с главами видны его лучшие результаты по вариантам 1 и 2.

Задача под одним номером во всех трёх вариантах проверяет одно и то же умение. Оценка: «5» — 7–8 верных ответов, «4» — 6, «3» — 4–5. Страница для родителей не защищена паролем: её просто нет в меню сайта.

Тема оформления по умолчанию следует системной, её можно переключить на светлую или тёмную. Выбранная тема и прогресс (решённые задачи и лучшие результаты экзаменов) хранятся в `localStorage` браузера.

## Уроки у доски

https://fryn3.github.io/math-v-kletochku/uroki/ — те же 40 тем анимированными уроками с озвучкой: картинка объясняет, голос рассказывает, проверки прямо в кадре. Справочник ведёт к ним: пункт меню «Уроки у доски», строка на главной и кнопка «Урок у доски» на странице темы. Ссылка с темы ставится, когда в списке курса книги `uroki/course.js` на её месте (глава и номер в главе) готовый урок с тем же названием, — так новая тема справочника без урока не получит чужую ссылку.

Книга собрана скиллом Papermorph; её исходники, озвучка и режим проверки озвучки (`papermorph/golos` — страница, где все записи слушаются, ударения правятся и шаги переозвучиваются) описаны в [`papermorph/README.md`](papermorph/README.md).

## Устройство

| Файл | Что в нём |
|---|---|
| `index.html` | разметка и стили |
| `js/core.js` | общее для сайта и страницы родителей: дроби в тексте, проверка ответов, оценка |
| `js/app.js` | оглавление, страницы тем, экзамены, шпаргалка, прогресс |
| `js/visuals.js` | SVG-рисунки: доли, числовая прямая, координатная плоскость, фигуры, многогранники и развёртки, клетчатая бумага, диаграммы, дерево вариантов |
| `js/ch1-*.js` … `js/ch9-*.js` | главы, по одному файлу на главу |
| `js/exams.js` | экзамены, варианты 1 и 2 |
| `roditelyam.html`, `js/parents.js` | страница для родителей: печать варианта 3 и ключ ответов |
| `js/exam-parents.js` | вариант 3; подключается только на странице для родителей |
| `uroki/` | книга «Уроки у доски»: обложка, уроки `ch01`–`ch40`, движок Papermorph в `uroki/lib/`; `uroki/course.js` — список курса, его читают и книга, и справочник |
| `papermorph/` | исходники уроков: тексты озвучки, ударения, инструменты озвучки и проверки (сайту не нужны) |

Тема — это объект в файле главы:

```js
{
  id: 'osnovnoe-svojstvo',            // адрес страницы: #osnovnoe-svojstvo
  title: 'Основное свойство дроби',
  base: ['drob', 'prostye'],          // на какие темы опирается
  rule: `<p>Общее правило</p>`,
  derive: [['Следствие', 'почему оно верно', 'пример']],
  trap: `<p>Частая ошибка</p>`,
  tasks: [{ q: 'Сократи {12/18}.', a: '2/3', hint: 'НОД(12, 18) = 6' }],
}
```

Номер темы (3.2) считается по её месту в главе, а ссылки вида «тема 3.2» в текстах написаны вручную. Поэтому новую тему удобнее ставить в конец главы. Если вставить её в середину, поправьте ссылки на темы, которые сдвинулись. Новые главы добавляйте только в конец: лучшие результаты экзаменов хранятся по номеру главы. Новые задачи в теме тоже добавляйте в конец списка: решённые задачи запоминаются по номеру.

Круговая диаграмма (`V.sectors`) рассчитана не больше чем на три части. Их цвета `--series-1…3` заданы в `index.html` и `roditelyam.html` и проверены на различимость, в том числе при нарушениях цветового зрения.

Задача экзамена записывается так же, как задача темы. В `exams.js` у неё два варианта и тема для повторения, в `exam-parents.js` — третий вариант с решением для ключа. Порядок задач в обоих файлах одинаковый:

```js
// exams.js
E[3] = [
  { t: 'osnovnoe-svojstvo', v: [
    { q: 'Сократи дробь {24/36}.', a: '2/3' },
    { q: 'Сократи дробь {45/60}.', a: '3/4' }] },
];
// exam-parents.js
E[3] = [
  { t: 'osnovnoe-svojstvo', q: 'Сократи дробь {35/56}.', a: '5/8', why: 'НОД(35, 56) = 7' },
];
```

Если в экзамене главы заменили задачи, увеличьте номер этой главы в `EXAM_VER` (`core.js`). Тогда лучший результат, полученный на прежних задачах, перестанет показываться в оглавлении и на странице для родителей.

После изменения JS-файлов увеличьте номер `?v=` у тегов `<script>` в `index.html` и `roditelyam.html` (в том числе после правки `uroki/course.js`: справочник подключает и его). Иначе браузеры могут до 10 минут брать старые скрипты из кэша GitHub Pages.

В текстах `{3/4}` превращается в дробь, а `{1 2/3}` — в смешанное число. Ответ проверяется по значению: подойдут `0,5`, `0.5` и `1/2`. Если дробь в ответе можно сократить, программа просит её сократить. Для текстовых ответов и ответов в заданной форме используются `text: true` и `exact: true`, для выбора из вариантов — `opts: [...]`.

## Запуск локально

```bash
python3 -m http.server 8765
```

После этого откройте http://localhost:8765.
